这里是 Minecraft Bedrock Edition 的开服路线。官方的 Bedrock Dedicated Server（BDS）可运行在 Windows 与受支持的 Ubuntu 环境中；它的启动方式、端口协议、配置文件与扩展机制都和 Java 版不同。若你的玩家使用手机、平板、Windows Bedrock Edition 或主机上的 Bedrock Edition，请从本板块开始。[1] [2]

<Callout tone="warning" title="不要套用 Java 版的服务端教程">
  Java 版的 Paper 插件、Forge/Fabric 模组和 JVM 启动参数不能直接用于 BDS。基岩版主要使用 `server.properties`、allowlist、资源包、行为包与 Add-On；开始前请确认客户端是 Bedrock Edition，而不是只根据设备类型判断。
</Callout>

## 开始之前先确认

| 需要确认的事 | 为什么重要 |
| --- | --- |
| 玩家使用 Bedrock Edition | Java 与基岩版不是同一套独立服务端；先选错版本，后续教程和扩展都可能不适用。 |
| 客户端与服务端版本匹配 | BDS 与客户端协议版本不一致时，官方文档列出的常见结果是 Outdated Client 或 Outdated Server。[1] |
| 使用独立的服务端目录 | 首次启动会生成世界、资源包和行为包相关目录；不要直接在下载压缩包或随意的客户端目录里混合操作。[1] |
| 先在本地验证 | 先看到 BDS 正常生成世界和控制台日志，再处理防火墙、端口转发或远程玩家连接。 |

完成第一次本机启动后，尽早创建世界和配置的备份。改动 allowlist、端口、资源包或世界文件之前，先停服并保留可回退副本；这样即使某个配置不适配当前版本，也能恢复到上一份可启动状态。
