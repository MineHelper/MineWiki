## 白名单与权限

服务器人多了以后，"谁能进来""谁说了算"就成了必须管的事。这篇讲最基础的三样：白名单、OP、封禁。

## 白名单：只让认识的人进

服务器默认谁都能连（知道地址就行）。只想让朋友玩，就开白名单：

1. 在服务端控制台输入 `whitelist on` 开启。
2. 用 `whitelist add 玩家名` 添加成员。
3. 用 `whitelist list` 查看当前白名单。

或者直接改 `server.properties` 里的 `white-list=true`。命令和改配置文件二选一就行，效果一样。

注意事项：

- 白名单是按**玩家名**记录的，对应 `whitelist.json`。
- 开服时就把白名单开好，等陌生人进服搞完破坏再想起来，就晚了。
- 正版服务器上，即使不开白名单，也只有正版玩家能进（`online-mode=true` 时）。

## OP：管理员权限

给玩家 OP，就是给他所有管理员权限（可以 `gamemode`、`tp`、`kick`、封人，基本等于半个服主）。

- 给：`op 玩家名`
- 取消：`deop 玩家名`

新手最常见的错误是**给朋友一个 OP 结果对方乱用权限搞事**。OP 是给信得过的人的，不是给所有人的。真正的做法是"最小权限"：谁需要什么功能，给什么权限。

## 权限插件才是正解

原生 OP 是"全有或全无"。想细分权限（比如让某人只能传送、不能封人），就要用权限插件，本 Wiki 推荐 **LuckPerms**：

- 玩家分到"组"（默认组、vip 组、管理员组……）。
- 每个组配置允许/禁止的权限节点。
- 用 `lp group default set <权限> true/false` 这类命令管理，命令以 `/lp` 开头。

权限插件的命令初看吓人，但只用最常用的几个就够：查看玩家权限、给组加权限、给单个玩家加权限。插件下载页和官方文档都有完整命令表，别怕。

## 封禁玩家

- `kick 玩家名`：踢出，能重进。
- `ban 玩家名`：封禁，拒绝进入。
- `ban-ip IP地址`：封 IP，防换号。
- `pardon` / `pardon-ip`：解除对应封禁。

封禁要留记录、说清楚原因，不然你自己都会忘。`banned-players.json` 和 `banned-ips.json` 就是干这个的。误封了记得解，封禁一个故意搞事的人，维护成本远低于让他反复捣乱。

## 小结

- 只给信得过的人 OP，管理靠权限插件而不是全员 OP。
- 白名单开服就开，别等出事再补。
- 封禁要留档、要解释原因，别随手乱封。
