## 白名单与权限

服务器人多了以后，"谁能进来""谁说了算"就成了必须管的事。这篇讲最基础的三样：白名单、OP、封禁。

## 白名单：只让认识的人进

服务端默认不会按“认识的人”筛选玩家。只想让朋友进入时，可以启用白名单：

1. 在服务端控制台输入 `whitelist on` 开启。
2. 用 `whitelist add 玩家名` 添加成员。
3. 用 `whitelist list` 查看当前白名单。

也可以在 `server.properties` 中启用 `white-list=true`。不同版本还可能提供 `enforce-whitelist`，用于在名单重载后踢出不在名单内的在线玩家；修改前先确认管理员账号不会被误踢。

注意事项：

- 白名单数据保存在 `whitelist.json`，包含玩家档案信息，不应手动随意改写 JSON。
- 白名单适合小型好友服，但它不替代权限管理和正常备份。
- `online-mode=true` 会验证玩家账号；它与白名单是两层不同的控制。

## OP：管理员权限

给玩家 OP，就是给他所有管理员权限（可以 `gamemode`、`tp`、`kick`、封人，基本等于半个服主）。

- 给：`op 玩家名`
- 取消：`deop 玩家名`

新手最常见的错误是**给朋友一个 OP 结果对方乱用权限搞事**。OP 是给信得过的人的，不是给所有人的。真正的做法是"最小权限"：谁需要什么功能，给什么权限。

## 权限插件才是正解

原生 OP 的权限粒度很粗。想细分权限（例如允许传送但不允许封禁），可以使用权限插件；LuckPerms 是常见选择，但命令和权限节点应以所安装版本的官方文档为准：

- 玩家分到"组"（默认组、vip 组、管理员组……）。
- 每个组配置允许/禁止的权限节点。
- 通过插件定义的权限节点和组规则管理；不要把示例命令当作所有版本都可直接复制的固定语法。

权限插件的命令初看吓人，但只用最常用的几个就够：查看玩家权限、给组加权限、给单个玩家加权限。插件下载页和官方文档都有完整命令表，别怕。

## 封禁玩家

- `kick 玩家名`：踢出，能重进。
- `ban 玩家名`：封禁，拒绝进入。
- `ban-ip IP地址`：按 IP 地址封禁；共享网络、动态 IP 或代理环境下可能误伤其他玩家。
- `pardon` / `pardon-ip`：解除对应封禁。

封禁要留记录、说清楚原因，不然你自己都会忘。`banned-players.json` 和 `banned-ips.json` 就是干这个的。误封了记得解，封禁一个故意搞事的人，维护成本远低于让他反复捣乱。

## 小结

- 只给信得过的人 OP，管理靠权限插件而不是全员 OP。
- 白名单开服就开，别等出事再补。
- 封禁要留档、要解释原因，别随手乱封。
