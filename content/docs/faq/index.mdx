# 常见问题总览

这里是速查页，按类别给你指路。绝大多数问题在对应章节都有完整解答，先翻再问，别一上来就贴"开服失败"四个字。

## 启动失败类

- 报 `UnsupportedClassVersionError` → Java 版本不对，《开服前的准备》。
- 报 `You need to agree to the EULA` → 去改 `eula.txt`，《首次开服完整流程》。
- 报 `Port 25565 already in use` → 端口被占用，《首次开服完整流程》。

## 连接失败类

- 局域网能连、外网连不上 → 《联机与网络》章节，先确认有没有公网 IP。
- 直接连 `192.168.x.x` 发给朋友 → 别人连不上，那是内网地址，《联机与网络》。
- 手机流量能连、家里电脑连不上 → 可能走了内网，测试方法见《端口转发》。

## 配置类

- 改了配置不生效 → 要重启服务端，《配置文件》。
- 想关 PvP / 改视距 / 改人数 → 《server.properties 详解》。
- 想让某人当管理员 → `op 玩家名` 或权限插件，《白名单与权限》。

## 插件类

- 插件装了没反应 → 重启、看日志、查依赖，《插件安装与配置》。
- 两个插件冲突 → 只留一个或查兼容设置，同上。
- 想要一套插件清单 → 《常用插件清单》。

## 模组类

- 客户端连不进来报版本不兼容 → 模组/加载器/版本没对齐，《安装模组服》。
- 不知道选 Forge 还是 Fabric → 《Forge 还是 Fabric》。

## 维护类

- 怕世界丢了 → 去读《备份与恢复》，这不是玩笑。
- 服务器卡 → 先分清楚是 TPS 还是网络，《服务器优化》。
- 想更新服务端但怕炸 → 《服务端与插件更新》，先备份。

## 提问的艺术

如果你翻完这些还是解决不了，提问时至少带上：

1. **服务端类型和版本**（Paper 1.21.1 / Fabric 1.20.4 ...）
2. **Java 版本**（`java -version` 的输出）
3. **完整报错日志**（`logs/latest.log` 的最后几十行）
4. **你做过什么操作**（改了哪些配置、装了哪些插件）

缺了这些，别人只能猜，你也只能得到一堆答非所问的"试试重启"。
