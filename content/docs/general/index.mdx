# MineWiki简介
👋 欢迎来到MineWiki！
MineWiki是一个主要针对游戏Minecraft新手服主的Wiki
在阅读前，请确认你拥有以下基础

- 具备基础的计算机操作技能-如解压、新建文件夹、打开文件、安装软件等
- 具备使用搜索引擎搜索关键词的能力
- 一台能够正常游玩 Minecraft 的电脑
- 具有一定的 英语基础

# 教程适合谁
- 渴望学习如何开设服务器并良好运营服务器的人；
- 寻求解决如何解决开服中遇到的的常见问题的人；
- 希望深化对开服基础知识理解的人。

# 教程不适合谁
- 意图通过开设服务器进行欺诈谋利的人；
- 忽视插件文档，频繁依赖他人解答的人；
- 头脑简单、狂妄自大、懒惰无能的人。
