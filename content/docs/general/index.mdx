MineWiki 面向第一次自己维护 Minecraft Java 版服务器的玩家。这里不追求把每个参数都讲一遍，而是先帮你把服务端稳定地跑起来，再逐步处理联机、插件、配置和日常维护。

## 开始前需要准备什么

你不需要有运维经验，但最好能完成这些基本操作：解压文件、创建文件夹、编辑纯文本、安装 Java，并能把报错信息复制出来。如果某一步看不懂，先停在原地查清楚，不要靠“多试几次”覆盖问题。

一台能运行 Minecraft 的电脑通常可以用于小规模自用测试。不过，能玩客户端不等于适合长期托管服务器：CPU 单核性能、可用内存、网络上行、硬盘空间和在线时长都会影响体验。

## 这套文档适合谁

- 想和朋友开一个原版、Paper 或模组服务器，并愿意自己维护它的人。
- 想搞清楚“为什么连不上”“插件为什么没加载”“更新后为什么报错”等具体问题的人。
- 希望建立备份、更新和排错习惯，而不是只复制一段启动命令的人。

## 建议的阅读顺序

1. **开服前的准备**：先选服务端和 Java，再评估内存与联机方式。
2. **首次开服完整流程**：在本机完成第一次启动，并确认日志、EULA 和世界生成正常。
3. **联机与网络**：先区分局域网、公网 IP 和内网穿透，再考虑开放给朋友。
4. **插件或模组服**：确认服务端类型、版本和依赖关系后再安装扩展。
5. **配置、备份与维护**：任何对外开放的服务器都应该尽早建立备份和更新流程。

## 先记住三条原则

> **先本机，后外网；先备份，后改动；先看日志，后问人。**

这三条看似简单，却能避免绝大多数新手事故。尤其是世界、插件和服务端更新：只要能回滚，问题就不会变成灾难。

## 目录导航

- **从这里开始**：准备环境与首次启动。
- **联机与网络**：端口转发、内网穿透和连接排查。
- **插件**：插件来源、安装、依赖与常用功能。
- **配置文件**：`server.properties`、白名单、OP 与权限。
- **维护与备份**：备份、更新、性能定位和日志。
- **模组服**：加载器、整合包和客户端兼容性。
- **常见问题**：按“启动失败”或“玩家连不上”快速定位。
