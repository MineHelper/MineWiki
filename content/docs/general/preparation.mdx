## 开服前的准备

开服这件事，八成以上的坑在开服之前就已经埋下了。先把下面几个问题想明白再动手，比你开起来之后天天救火要划算得多。

## 先想清楚你要开一个什么样的服

这不是废话。原版生存、插件生存、模组服、小游戏服，这几种服务器对硬件、服务端和运维的要求完全是两个量级，选错了后面全是折腾。

- 原版 / Paper 生存服：门槛最低，几个人好友联机，一台普通电脑就够用。
- 插件生存服：核心问题在内存和插件质量。一口气塞几十个插件还互相冲突的服，比不开服还难受。
- 模组服：先分清"客户端模组"和"服务端模组"是两个概念，很多新手第一道坎就栽在这上面。
- 小游戏服：对网络要求高，单区块玩家密度大，优化压力最大。

建议先开一个原版或 Paper 的生存服把全流程跑通，再考虑往上加东西。一上来就搞小游戏服，大概率会在优化上耗到放弃。

## 内存怎么选

MC 服务端对内存的胃口相当固定，摸清规律就不会瞎买：

- 1.8 - 1.12（Java 8）：2G 够 10 人左右
- 1.17 - 1.20.4（Java 17）：至少 4G，推荐 6G 以上
- 1.20.5 及以上（Java 21）：6G 起步比较稳

有一条反直觉的常识：不是内存越大越好。给服务端分配远超实际需要的堆内存，GC 反而会频繁触发，掉 TPS。机器有 8G 你却只开四人服，分配 4G 就够了，别贪。

## Java 别装错

版本对应关系：

- 1.8 - 1.16 用 Java 8
- 1.17 - 1.20.4 用 Java 17
- 1.20.5 及以上用 Java 21

注意 Oracle 官方已经停止提供 JDK 8 的免费下载，去 Adoptium 下载 OpenJDK 即可。装错版本最常见的是报 `UnsupportedClassVersionError`，看到这行报错先检查 Java，别急着怀疑服务端文件坏了。

## 在哪开

- 自己的电脑：免费，但断电、断网、合盖，别人就进不来了，而且这台电脑基本上没法干别的。
- 云服务器 / VPS：灵活可控，但如果你买的是 Linux 系统，得会一点基础命令。
- 面板服（Minecraft 专用面板）：最省心，但通常比同配置的 VPS 贵，而且很多便宜面板服性能拉胯。

个人建议：先在自己电脑上跑通流程，觉得稳定了再决定要不要上云。服务器性能瓶颈往往不在"开得多快"，而在后期优化和网络质量。

## 让别人能进来

如果只在内网几个人联机，这条可以跳过。要让公网玩家进来，通常三条路：

1. 公网 IP + 路由器端口转发（默认 TCP 25565）
2. 内网穿透 / frp
3. SRV 记录配合域名（可选，配合第一条使用）

端口转发是新手最容易卡住的环节，后面的教程会单独开一篇详细讲。
