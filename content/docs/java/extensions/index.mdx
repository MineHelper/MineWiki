Java 版的“扩展”至少分为两条不同路线：**插件**通常运行在兼容 Bukkit/Paper API 的服务端上；**模组**则依赖 Forge、NeoForge 或 Fabric 等加载器。它们的文件格式、安装目录、客户端要求和排错方式都不同。先确认你正在运行的服务端类型，再选择下面的入口。

<Callout tone="warning" title="不要把插件与模组混装">
  Paper/Bukkit 插件不能直接当作 Fabric、Forge 或 NeoForge 模组加载；反过来也是一样。来源不明的“混合端”通常会增加兼容性与数据恢复风险，部署前应先阅读其官方支持范围。
</Callout>
