## 玩家连不上服务器

"玩家连不上"是本 Wiki 最常被问的问题，但九成案例都能用同一个排查顺序解决。按下面顺序走，别跳步。

## 第一步：确认服务器真的在跑

听着像废话，但真的有人发"连不上"时，服务端压根没开。先确认：

- 服务端窗口还在吗？崩了没？
- 控制台输入 `list`，有响应说明活着。
- `server.properties` 里 `server-port` 是多少？确认你连的端口没错。

## 第二步：分清是本地连不上还是外网连不上

**先在服务器本机连 `localhost:端口` 测试**。能进，说明服务端没问题，问题在网络环节；连不上，说明服务端本身就有问题，先修那个。

本机能连、外网连不上，进入下一步。

## 第三步：按网络排查

1. 你有公网 IP 吗？没有 → 端口转发做了也没用，直接走《内网穿透》。
2. 有公网 IP → 检查《端口转发》里的规则：端口、内网 IP、协议、防火墙放行。
3. 用了内网穿透 → 检查隧道配置，回《内网穿透》看。

## 第四步：让玩家检查自己的客户端

别一上来就觉得是你服务器的问题，先让玩家确认：

- 客户端版本和服务端一致吗？（尤其是模组服，《安装模组服》有讲）
- 地址格式对吗？`IP:端口`，别少了端口。
- 玩家自己是不是也在拿内网地址连？

## 典型场景速查

| 现象 | 原因 |
| --- | --- |
| 本机能进，朋友连不上，你家没有公网 IP | 运营商 NAT，走内网穿透 |
| 手机流量能进，家里 Wi-Fi 进不去 | 测试环境问题，用流量测试为准 |
| 提示 Connection refused | 服务端没在端口上监听，或防火墙没放行 |
| 提示 Connection timed out | 网络路径不通，多半是转发/穿透没生效 |
| 提示 Can't connect，玩家却说能连别的服 | 你的公网 IP 或端口写错了 |

## 最后再想一下

如果你和别人排查了半天还是不行，回头检查一件事：**你是不是把 `localhost` 或内网地址发给玩家了？** 这是发生频率高到离谱的一个错误。
