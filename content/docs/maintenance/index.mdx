# 日常维护

服务器开起来不等于一劳永逸。日常维护要做的事很少，但每件都影响服务器的寿命和玩家体验。

## 每天该做的

- **看一眼日志**：`logs/latest.log` 里有没有红色报错。不用逐行读，出现 `ERROR`、`Could not`、`Exception` 字样就留意一下。
- **确认服务端没崩**：人都进不去、控制台半天没反应，先看是不是服务端卡死或崩了。

## 每周该做的

- **做一次备份**（下一篇详细讲，但先记住这个频率：至少每周一次）。
- **清理旧日志**：`logs/` 下会积累很多旧日志，占空间不大但乱，定期删旧的没毛病。
- **检查插件更新**：`plugins/` 里的插件有没有新版本。很多插件修 bug 都靠更新，长期不更等于裸奔。

## 玩家多了以后

- 及时处理玩家纠纷：在服里吵架、刷屏、互相破坏，别拖，拖到最后是人心散了。
- 留意"谁在深夜上线拆家"这类恶性行为，装个 CoreProtect（方块记录）能帮你事后查证。

## 什么时候需要重启

- 改了配置、装了插件：必须重启，不解释了。
- 服务器开始卡顿、`list` 响应变慢：先重启试试，往往能缓解。
- 长时间运行的服务器（一周以上）：有内存泄漏嫌疑，重启一次比调半天配置见效快。

## 别做这些

- **别在服务器运行时直接拖文件进去替换配置**：要么你动的是"内存里正在用的文件"，要么改完不生效，还会把文件弄坏。要动文件，先 `stop`。
- **别把服务器开着不管就跑路**：服务端崩了没人重启，玩家干等。要么盯着，要么用进程守护工具（比如 Linux 下的 systemd、Windows 下的 NSSM）。
- **别把控制台密码/密钥发给别人**：控制台能执行服务端命令，交给别人等于把服务器钥匙交出去。

## 一句话总结

日常维护的核心就两件事：**备份**和**看日志**。这两样做到了，大部分坑都能在造成损失前被发现。
