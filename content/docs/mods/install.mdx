# 安装模组服

以最省心的方式讲：**用 CurseForge 的整合包开模组服**。自己手搓模组列表太容易崩，新手别干。

## 方式一：用整合包自带的开服工具

很多整合包在 CurseForge 下载页有"Server"相关的下载说明，会提供：

- 一个服务端文件（通常是 `.jar` 或安装脚本）。
- 一份明确的版本要求（Java 版本、内存要求）。

步骤和原版/Paper 开服大同小异：

1. 下载服务端文件，放到独立文件夹。
2. 按说明装对应版本的 Java（Forge/Fabric 对 Java 版本要求严格，回看《开服前的准备》）。
3. 启动安装程序，选择"安装服务端"。
4. 启动后同意 EULA，等待世界生成。

**特别注意**：整合包下载页一般会写明"服务端版本必须和客户端完全一致"，包括模组列表。玩家要用同一个整合包启动，才能连进来。

## 方式二：自己搭 Forge / Fabric 服务端

1. 去 Forge 或 Fabric 官网下载对应 MC 版本的服务端安装器。
2. 运行安装器，选择"Install Server"，生成一个 `server.jar`。
3. 把想装的模组 `.jar` 放进 `mods/` 文件夹。
4. 启动 `server.jar`，同意 EULA。

这里最痛苦的就是**版本对齐**：模组要匹配 MC 版本、加载器版本，甚至可能要求特定的 Java。一版对不上，加载就报错。

## 客户端连不进来？先查这几样

模组服连不上的头号原因，永远不是网络，是**客户端不匹配**：

- 客户端是否装了同一个整合包 / 同一份模组列表？
- MC 版本是否一致？
- 加载器版本是否一致？

"版本不兼容"（Incompatible mods）之类的报错，优先怀疑模组列表和版本，别急着检查端口转发。

## 模组服的备份

模组服的世界和配置文件比原版更脆弱（很多模组有自己独立的配置文件，在 `config/` 文件夹里）。备份时整个服务器目录一起拷，别只拷 `world/`。具体方法回看《维护与备份》章节。

## 常见问题

**Q：服务端启动后没有 `mods/` 文件夹？**
首次启动后生成，或者手动建一个同名文件夹。

**Q：玩家说"服务器只有 1.20 但我要 1.20.4"？**
小版本不一致也不行，模组服对版本极度敏感，务必对齐。

**Q：模组装了一堆，启动报一堆错？**
先删掉最近装的那几个，逐个排查。一次只加一两个模组，比一次装十个好排查一百倍。
