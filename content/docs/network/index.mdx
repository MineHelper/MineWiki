# 联机与网络

服务器跑起来了，但别人连不上，是新手问得最多的问题。这一章把"怎么让玩家进得来"这件事讲透。

先说结论：联机本质上就三件事——玩家知道连哪个地址、这个地址能通到你的电脑、你的服务端在那个端口上等着。

常见的三种方案：

1. 公网 IP + 端口转发：最正规，也最一劳永逸，但要求你有公网 IP。
2. 内网穿透：家里是内网也能玩，代价是要跑一个转发服务，延迟和稳定性看第三方脸色。
3. 面板服 / VPS 直连：服务商已经帮你把网络搞定了，直接填地址就能连。

大多数新手卡在"端口转发"这一步，下一篇详细讲。如果你家宽带压根没有公网 IP，直接看内网穿透那篇。

## 几个先要搞明白的概念

- **IP 地址**：你在网络上的门牌号。玩家连接的地址就是 `IP:端口`。
- **端口**：电脑上 65535 个"门"之一，MC 默认走 25565。一个端口同时只能被一个程序占用。
- **公网 IP vs 内网 IP**：192.168.x.x 开头的是内网地址，只在你自己家里有效，外面的人连的是你的公网地址。

很多人分不清这两种 IP，以为把 `192.168.x.x` 发给朋友就行——当然连不上，这是你家的内部地址，别人根本路由不到。
