# 内网穿透

上一篇说得很清楚：运营商没给你公网 IP，端口转发就是死路。这时只能用**内网穿透**：把你服务端的端口"映射"到一台有公网的服务器上，玩家连那台服务器，流量再转回你家里。

## 原理

```
玩家 → 公网服务器(转发节点) → 你家路由器 → 你的电脑
```

你的电脑持续和一台公网服务器保持一条长连接，公网服务器对外提供一个 `节点域名:端口`，玩家连的是它。代价是中间多跳了一次，延迟会变高。

## 常见工具

- **frp**：最常用，自建穿透服务器用这个，配置稍微复杂。
- **Sakura Frp**：国内面向游戏场景的免费穿透服务，有专用游戏节点，新手首选。
- **花生壳**：老牌，但免费档对游戏场景性能一般。

免费的穿透服务体验差别很大，高峰期排队、限速、节点掉线都是常态。如果只是几个朋友玩，够用；想长期稳定运营，还是建议想办法上 VPS 或面板服。

## 用 Sakura Frp 走一遍（以官方文档为准）

1. 注册账号，实名认证（国内服务都要）。
2. 官网找自己的 `访问密钥`，它是你登录客户端和创建隧道的凭证，别泄露。
3. 下载对应系统的客户端（Windows 下通常是一个压缩包，解压即用）。
4. 在网页后台创建隧道：软件选"Minecraft"，本地 IP 填 `127.0.0.1`，本地端口填 `25565`（或你服务端实际端口）。
5. 启动客户端，会分配给你一个类似 `xxxxx.freefrp.org:12345` 的地址，这就是别人要连的地址。

注意具体操作以 Sakura Frp 的官方文档为准，界面经常改，别照着这篇截图对。

## 玩游戏时的延迟

穿透的本质是借道，延迟不可避免。给玩家的建议：

- 选节点时尽量靠近玩家所在地，别跨半张地图。
- 免费节点一般比付费节点慢，高峰期更明显。
- 你自己作为服主，也不要用它进服，用局域网 IP 直连测试最快。

## 什么时候该放弃穿透

出现下面情况，就说明该换方案了：

- 高峰期玩家频繁掉线、卡顿，日志里全是连接超时。
- 免费节点的延迟已经影响正常游玩（比如 PvP）。
- 你想认真运营一个稳定的服务器。

到这一步，认真考虑租一台 VPS 或者直接上面板服。服务器放公网，比在自家卧室里跑要省心得多——断电、断网、家人拔网线这些事，都跟你没关系了。
