# 常用插件清单

先说规矩：**插件不是越多越好**。每多一个插件就多一分冲突和卡顿的可能。下面这份清单是"够用"的标准，按需取用，别照单全收。

## 核心必备

| 插件 | 作用 | 说明 |
| --- | --- | --- |
| EssentialsX | 基础命令库（/home /tpa /spawn /kit 等） | 生存服标配，几乎必装 |
| Vault | 经济/权限前置库 | 不是功能插件，是给其他插件用的 API |
| LuckPerms | 权限管理 | 给不同玩家分配不同权限，学一下基本语法，收益很大 |
| WorldGuard + WorldEdit | 领地保护 / 区域编辑 | WorldEdit 是 WorldGuard 的前置，两者搭配 |

有了这四样，一个基础生存服的骨架就搭起来了。剩下的都算锦上添花。

## 推荐考虑

- **EssentialsX 附属模块**：家、邮箱、聊天前缀等，按需启用。
- **CoreProtect**：方块操作日志，防熊、回滚的利器，出了事能查"谁动了我的房子"。
- **Slimefun / 类插件**：想搞点玩法深度再上，别新开服就装，机制太重。
- **DiscordSRV**：服务器和 Discord 互通，国内用得少，按需。

## 别急着装的

- 各种"优化"插件：**先别装**。大部分号称优化的插件，效果存疑，还可能和其他插件冲突。Paper 本身的性能已经足够好，先跑起来看数据，真卡了再针对性优化。
- 一堆花里胡哨的小功能插件：`/hat`、粒子特效、随机传送……等核心玩法稳定了再考虑，不然你的 plugins 文件夹就是灾难现场。
- 盗版/国内社区所谓"完美整合包"：来源不明，插件本身就是安全风险，前面讲过了。

## 装完顺序建议

1. 先装 LuckPerms，配好权限（自己给自己设 `*` 或对应组）。
2. 再装 EssentialsX，测试基础命令。
3. 然后 Vault + WorldGuard + WorldEdit，配领地。
4. 稳定跑几天，再加你想加的东西。

这个顺序的核心思路：**基础命令和权限先通，再谈别的**。权限没配好就装一堆功能插件，你连谁有权用什么命令都理不清。

## 插件自带配置别急着改

大部分插件默认配置对新手够用，别一上来就把 `config.yml` 从头改到尾。先用默认跑着，遇到具体需求再去文档里找对应配置项——插件文档（一般是插件下载页或 GitHub README）比任何教程都准确，别人转载的教程很可能过期。
