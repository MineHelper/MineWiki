## 插件入门

插件是给服务端加功能的扩展程序。生存服常见的玩法——`/home`、`/tpa`、经济系统、领地保护——基本都靠插件实现。注意这是**服务端插件**，和**客户端模组（Mod）**是两回事，别混。

## 前提：服务端必须支持插件

原版服务端（`server.jar`）不支持插件，想让插件跑起来，服务端得换成支持插件的类型：

- **Paper**：目前插件服的绝对主流，性能和兼容性最好，本 Wiki 推荐。
- **Spigot**：Paper 的老前辈，兼容所有插件，但性能不如 Paper。
- **Purpur / Pufferfish**：Paper 的分支，加了更多可调参数，进阶再研究。

一句话：新开服直接用 Paper，别纠结。

## 去哪找插件

### 推荐渠道

- **[Modrinth](https://modrinth.com)**：现代、干净、审核较严，Paper 插件和 Fabric 模组都能在这找。
- **[SpigotMC / Bukkit 官方论坛](https://www.spigotmc.org)**：老牌社区，插件最多最全，但鱼龙混杂。
- **[Hangar](https://hangar.papermc.io)**（Paper 官方）：Paper 团队维护的插件站。

### 别碰的渠道

- 各种"整合插件包"、付费定制群、来路不明的网盘链接——里面藏后门挖矿木马的概率，比你想象的高得多。
- 需要你输入服务器密码/开服命令才能"安装"的所谓插件。

## 怎么判断一个插件靠不靠谱

下载前先看几样东西：

1. **最近更新时间**：两年没更新还宣称支持 1.20+ 的，多半是假的，或者拉了个旧版改了改描述。
2. **下载次数和评论区**：几百次下载、评论区全是赞的，谨慎。
3. **文件大小和格式**：插件是 `.jar` 文件，一般几十 KB 到几 MB。要你下载 `.exe`、`.bat`、`.zip` 然后"解压后运行"的，直接关掉。
4. **来源域名**：插件页面的域名跟 Modrinth、SpigotMC 对不上，那就是搬运站，可能有毒。

## 支持 1.21+ 的新情况

新版 Minecraft 的插件生态正在往 **Fabric 模组** 迁移（很多主流插件如 LuckPerms 也出了 Fabric 版）。如果你开的是最新版本，可能遇到"想要的插件只有 Spigot 版、Paper 上不好用"的情况。这不是你操作问题，是生态现状，选服务端前先确认你要的核心插件支持哪个服务端。
